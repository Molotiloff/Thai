# КТ в покупке и продаже

Необязательные поля `counterparty_client_id` и `counterparty_spread` задаются
при создании обмена и при исправлении проведённого обмена в CRM. КТ выбирается
из активных клиентов с активной привязкой Telegram-чата. Спред задаётся в THB
за 1 USDT, например `0.15`, а не в процентах и не в целых копейках.

Для пары THB/USDT используются согласованные суммы: Q — количество USDT,
R — количество THB / Q, S — спред КТ. Начисление равно Q × S / R USDT,
округление HALF_UP до точности USDT-кошелька (6 знаков). Курс обменника:
R − S когда выдаём THB (продаём баты), R + S когда получаем THB (покупаем баты). Пример: Q=1000, R=33.1, S=0.15:
150 THB спреда, 4.531722 USDT КТ; курсы 32.95 и 33.25 соответственно.
Для пары THB/другая валюта Q — её USDT-оценка через обычный механизм
оценки обмена; неоценимый обмен не проводится.

Комиссия — дополнительная кредитовая строка USDT-кошелька КТ в той же
операции fx_trade. Балансирующая прибыль обменника уменьшается на эту сумму;
при недостаточной марже возникает убыток. Касса и договорные суммы клиента
из-за комиссии не меняются. Курс обменника сохраняется отдельно для справки,
не подменяет исходный курс котировки и повторно не уменьшает прибыль.
Отчёт и закрытие прибыли берут уже уменьшенный результат из журнала.

Начисление происходит только при проведении. В кассовой заявке оно возникает
после подтверждения обеих сторон. Повтор команды не начисляет деньги повторно.
Сторно отменяет одновременно обмен и начисление. Обычные проверки закрытого
периода и последующих движений продолжают действовать.

Историческое исправление пересчитывает комиссию в одной транзакции с обменом
и последующими движениями. При замене КТ учитываются последующие движения
как старого, так и нового получателя. Пересозданные последующие обмены сохраняют
своего КТ и договорный спред. Ошибка откатывает всю транзакцию. КТ можно убрать,
отправив исправленные условия без этих полей. Редактирование исходных сумм
через Telegram сохраняет ранее заданного КТ и пересчитывает его начисление;
новый синтаксис Telegram-команды для назначения КТ не вводится.

Проверенный пример фактической продажи батов: закупка 336000 THB за 10000 USDT
по 33.6, затем получение 1000 USDT и выдача 33100 THB по 33.1. Себестоимость
выдачи 985.11904762 USDT, прибыль до КТ 14.88095238, начисление КТ 4.531722,
чистая прибыль 10.34923038 USDT. Имена sale/purchase в существующем интерфейсе
классифицируют встречную валюту; направление спреда определяется движением THB.
