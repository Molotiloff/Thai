# SkyEx CRM · Таиланд

Независимый филиал SkyEx: общая касса, наличный и безналичный бат — отдельные
счета; оценка, оборотка и прибыль — USDT. В кошельках восемь инструментов.
Капитал собственников/инвесторов, займы группы «Партнер» и долги по расходам
учитываются раздельно. Отрицательные кошельки клиентов разрешены.

## Запуск

- Backend и Telegram: `.venv/bin/python main.py`.
- Только API: `.venv/bin/python -m api.thai_server`.
- Совместимый старый запуск `python bot_app.py` ведёт в тот же изолированный runtime.
- Настройки берутся только из `.env.thai`; образец — `.env.thai.example`.
- Отдельная PostgreSQL — порт **5433**, API по умолчанию **8001**.
  База российского проекта на **5432** не используется.
- Frontend — существующая копия `bookkeeping thai`; оформление и компоненты SkyEx РФ.

Перед запуском примените миграции через процедуру развёртывания с резервной копией.
Текущая ревизия схемы — `thai_0018`. Действующие процессы пользователь перезапускает вручную.

## Команды и работа

`/start` создаёт клиента и восемь кошельков. `/кошелек` и `/дай` показывают остатки;
кнопки выгружают месячную/полную XLSX-выписку. `/пт 100 обат 3500` — обмен
в кошельке; `/депбат` и `/выдбат` создают кассовые заявки с прежними карточками/PIN.
Фактический расчёт идёт после готовности, с номером Б-…; двухвалютная касса
проводится одной операцией после подтверждения обеих сторон.

`/отпр` ожидает реальные исходящие USDT TRON, `/бест` ведёт BestChange.
Доля Данияра сразу зачисляется на «Баланс Данияр» с сообщением «Прибыль с Бест». Комиссия CoinDrop накапливается и выплачивается отдельно за завершённые месяцы.
Внутренний курс вычисляется по объёму проведённых покупок и продаж в обоих направлениях.
Например, 100 USDT ↔ 3300 THB и 100 USDT ↔ 3500 THB дают 34 THB/USDT.
Внесения и ручные изменения кошелька не требуют курса; до первого обмена возможен
учёт без оценки USDT. `/курс`, `/курсы` и API ручных курсов удалены.
Сервис ордеров удалён по решению пользователя;
города, доставка, российские офисы, юань, инвойсы и Google Sheets не подключаются.
Старые английские финансовые команды отключены; бот и CRM используют общие сервисы.

## Проверки

`.venv/bin/python -m pytest tests/unit tests/thai tests/design -q`

`.venv/bin/ruff check .`

Финансовые тесты создают временные базы на 5433, Telegram и внешние шлюзы
подменяются mock. Российская схема, миграции и `tests/db` удалены;
доступна только Thai-цепочка. Оставшиеся медиасценарии, `/заявка` и ручная приёмка настоящим ботом
перечислены в плане интеграции.
