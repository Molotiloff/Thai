# Проверки backend Thai CRM

Из каталога backend:

```bash
.venv/bin/python -m pytest -q
.venv/bin/python -m ruff check .
```

Полный suite состоит из tests/unit, tests/thai, tests/design и tests/message_archive.
Российские tests/db, их миграции и fixtures удалены. Корневой conftest не загружает
.env и не использует DATABASE_URL/TEST_DATABASE_URL для подключения.

Финансовые тесты создают временные базы через tests/postgres.py по
THAI_TEST_DATABASE_URL из окружения или локального .env.thai.
Нужны локальный отдельный PostgreSQL на 5433, createdb/dropdb/pg_dump и отдельная
тестовая роль с CREATEDB. Рабочую базу тесты не очищают, порт 5432 запрещён.
Без тестового DSN DB-тесты пропускаются; такой прогон не подтверждает SQL-схему.

- tests/unit: команды, парсинг, политики, конфигурация и изоляция миграций.
- tests/thai: журнал, касса и себестоимость, кошельки, капитал/FIFO/проценты,
  займы, расходы/выписки, прибыль/BestChange, роли, outbox и восстановление.
- tests/design: ограничения архитектурного SQL-проекта.
- tests/message_archive: сохранение, поиск, медиа и экспорт сообщений.

Миграционные тесты применяют единственную цепочку thai_0001 → thai_0021,
проверяют повторный upgrade и нулевой seed, сравнивают PostgreSQL DDL со schema.sql.
Отказ на чужой/российской схеме проверяется на временной базе с имитацией
чужих таблиц, без загрузки исторических миграций РФ и без подключения к 5432.
Прямой Alembic также читает только .env.thai, не наследует российский DATABASE_URL.
Telegram и внешние платные шлюзы подменяются тестовыми адаптерами.
