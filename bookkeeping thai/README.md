# SkyEX Thai CRM · bookkeeping thai

Отдельный интерфейс тайского обменника на основе копии bookkeeping. Исходный
bookkeeping не изменён. Учётные правила и расчёты выполняет Thai backend;
frontend отображает точные десятичные строки и отправляет команды.

## Локальный запуск

1. В backend `CRM THB`: `.venv/bin/python -m api.thai_server`.
   Он читает `.env.thai` и использует отдельную Thai БД на 5433; API — 8001.
2. В этой папке `.env.local`:
   ```dotenv
   THAI_API_BASE_URL=http://127.0.0.1:8001/api/v1
   ```
3. `pnpm install` при отсутствии зависимостей, затем `pnpm dev`.
4. Открыть `http://localhost:3001`. Получить `/token` у отдельного Thai-бота
   и войти. Роль и права проверяются сервером. Без настроенного бота
   production-вход нужно настроить на этапе E10.

Старые `.env`, NEXT_PUBLIC_API_BASE_URL, mock/dev-bypass и российский JWT
не используются новым интерфейсом. THAI_API_BASE_URL — серверная переменная,
не NEXT_PUBLIC. Браузер отправляет команды в same-origin `/api/thai/*`;
JWT хранится в отдельной HttpOnly/SameSite cookie. В production нужен HTTPS.

## Страницы

Главная, клиенты с восемью кошельками, сделки, оборотка, займы клиентов группы
«Партнер», расходы с месячной выпиской, прибыль USDT, BestChange и журнал.
Каждый документ содержит ссылку на финансовую операцию. Отрицательный
клиентский кошелёк разрешён. Оборотка не входит в кошелёк или займы.

В оборотке доступны ставка инвестора, исходные вклады и курсы, FIFO-снятия,
ручное утверждение месячных процентов и отдельные выплаты. Собственники
получают доли прибыли вместо процентов на капитал.

Формы сохраняют ключ и дату команды при сетевом повторе. После успеха
повторное проведение отключено; кнопка «Новая операция» создаёт новый ключ.
При закрытом месяце корректировка требует ID соответствующей ревизии.
Возвратные депозиты отложены и в релизных формах отсутствуют.

## Проверки

```sh
pnpm typecheck
pnpm lint
pnpm build
pnpm start
```

Dev и start используют порт 3001. Backend/API и исходный bookkeeping
запускаются отдельно. Старые компоненты сохранены как исходный скелет,
но релизные страницы используют `src/thai`; старые разделы перенаправлены.
Подробности реализации и приёмки: `architecture/thai/IMPLEMENTATION_E9.md`
в backend-проекте. Общая эксплуатационная приёмка — этап E10.
